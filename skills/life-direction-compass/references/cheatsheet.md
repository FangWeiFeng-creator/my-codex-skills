# 决策规则速查 — 人生方向罗盘（四书融合）

| 能力 | 一句话规则 |
|---|---|
| 观察思维并暂缓评判 | 将重复念头标记为想法，观察后回到一项当前可核实事实。 |
| 用身体感受锚定注意 | 征得同意后，用中性身体感觉或自然呼吸把注意带回当下，并允许随时停止。 |
| 观察强烈情绪而不与之认同 | 给情绪命名、察觉一个身体信号、暂停冲动动作，再选安全的一步。 |
| 承认当下事实后处理可改变部分 | 先列现实事实，再分可改变、需协商和未知部分，为可改变部分选一步行动。 |
| 从自己的重复行动反思个人意义 | 回看多个近期选择，归纳用户想保护或获得的事，并请用户用反例检验。 |
| 用工作、社会关系和亲密关系检查生活任务 | 用用户定义的工作/成长、关系和社会参与领域比较选项影响，不固定价值排序。 |
| 把合作与贡献作为可选的审视角度 | 检查一个方向的合作/贡献机会、互惠、边界和个人成本。 |
| 遇到灰心时找具体受阻点并给予鼓励 | 将全盘自责改写为具体失败环节，再找一个支持或调整选项。 |
| 观察自己的思考过程 | 把重要判断拆成观察、解释、假设、替代解释和能改变判断的证据。 |
| 调节练习难度到可承受的挑战区 | 定位中断环节，每轮只调整一个难度因素，用反馈决定继续、加难或减量。 |
| 用输出和错误反馈调整练习 | 为一个真实目标做小型输出，观察错误或反馈，再选下一轮的具体练习点。 |
| 写下待办、优先级、时间与实际完成 | 列任务、按用户标准排序、安排少量时间并记录实际完成和调整。 |
| 用小行动积累经验以澄清目标 | 给一个未知方向设计可逆的小实验，设成本上限、观察指标、时间窗和退出条件。 |
| 检查注意是否跟随当前行动 | 标明当前动作与干扰来源，判断干扰是否紧急，再回到短动作或重排计划。 |
| 降低并行任务并给日程留余地 | 列出并行目标与固定责任，由用户选焦点，暂缓可改事项并留出缓冲。 |
| 在专注下降时主动休息 | 观察疲劳与外部原因，在休息、换轻任务、调整环境或求助中选择分支。 |
| 用具体行动检验自己所知 | 将用户自选原则转成一项可观察行为，记录障碍和结果作为信息。 |
| 按用户自选标准复盘并修正 | 按用户自选标准复盘一件行动，区分可控/外部因素并选择修复或下一次改法。 |
| 换角度检查情绪与处境 | 列出当前解释、两个合理替代解释及区分这些解释的证据。 |
| 用关系、能力和自主需要作选择复盘 | 比较选项对用户自定义的关系、能力与自主空间的影响，不计算总分。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
