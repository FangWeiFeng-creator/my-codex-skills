# Book overview — 人生方向罗盘（四书融合）

> “觉察 → 澄清 → 选择 → 实践 → 复盘”是本任务的工作性综合，不是四位作者共同提出的模型。

## 四个来源的层次

| 来源 | 可支持的反思角度 | 不可冒充为 |
|---|---|---|
| 埃克哈特·托利《当下的力量》 | 观察思维、情绪和当前事实；区分承认事实与停止行动 | 临床机制、安全评估或放弃改变的理由 |
| 阿尔弗雷德·阿德勒《自卑与超越》 | 工作/成长、关系和合作等生活任务；从重复行动提出假设 | 现代诊断、固定人格结论、普遍婚恋/性别标准 |
| 周岭《认知觉醒》 | 元认知、难度调整、行动/学习反馈、计划与休息 | 已验证的脑科学总模型、健康处方或未核实数字 |
| 于立志《王阳明心学智慧》 | 以用户自选原则检查行动并复盘 | 王阳明原典或所有人都必须遵守的道德/政治标准 |

## 运行原则

1. 确认用户问题、事实、解释、未知与风险；不把猜测写成事实。
2. 方向由用户价值、责任、资源和限制决定，不由外部替用户宣布唯一使命。
3. 若方向缺少经验，可设计可逆、小成本、有退出条件的试验；这是本 Skill 的安全实现约定。
4. 行动安排需要合适难度、可观察反馈和恢复空间；不把时长、打卡或痛苦当成果。
5. 复盘以具体修正为终点；失败不能自动归因于用户，结构性限制不能被个人成长叙事抹去。

## 全局停止边界

- 紧迫危险、暴力/胁迫、自伤风险或急迫医疗问题出现时，暂停常规人生规划，优先现实安全与适当人类支持。
- 不用觉察、臣服、贡献、坚韧或知行合一劝用户留在危险环境、忽略边界或承担不属于自己的责任。
- 不提供心理/医学诊断、法律/财务结论或健康处方；必要时补充合格证据和专业意见。
- 若练习加重痛苦、羞耻或强迫性反刍，立即停止并转向现实支持。
