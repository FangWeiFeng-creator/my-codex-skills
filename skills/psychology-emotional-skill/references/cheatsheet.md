# 决策规则速查 — 心理学情感技能

| 能力 | 一句话规则 |
|---|---|
| 个人意义与生活方式复核 | 先形成可反驳的生活方向假设，再决定一个可逆试验。 |
| 关系建议的证据分流 | 先判断证据类型，再决定能否把建议迁到当前关系。 |
| 吸引与匹配条件扫描 | 把吸引拆成可观察条件，用真实信息和未知项取代保证。 |
| 关系认知与归因复核 | 把事实、解释和动机分开，用可更新的证据谈判。 |
| 冲突前沟通修复计划 | 描述一次具体行为，协商一个可检查的下一步。 |
| 相互依赖与承诺检查 | 分开满意、替代、投入与安全，再决定下一步。 |
| 冲突升级与修复路径 | 先打断升级循环，再选可逆的协商试验。 |
| 亲密关系权力与安全分诊 | 出现恐惧、强迫或伤害时，先保护安全与退出自由。 |
| 关系维护与修复计划 | 选择少量双向维护动作，用观察窗口检验。 |
| 低压、双向选择的相识与约会计划 | 用情境化、真实、可拒绝的一次互动替代保证爱意的技巧。 |
| 具体、真实、互惠的承认计划 | 承认一项可核对的事实，并保留不被接受的空间。 |
| 人际影响策略识别与边界应对 | 识别影响手法与不对称，争取核实时间并保留拒绝。 |
| 性与亲密偏好的同意对话 | 逐项询问、逐次确认，把不确定视为未同意。 |
| 关系类型与爱情阶段定位 | 用多维证据和双方共识描述关系，不用单一信号命名。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
