# 心理学情感技能 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 心理诊断、危机处置、法律结论或对他人动机的读心。
- 保证挽回、让对方爱上、操控、隐瞒、窥探、威胁或报复。
- 未成年人性内容；绕过同意或利用依赖、醉酒与权力不对等。
- 替代紧急服务、专业医疗/心理服务或安全机构。

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 先分清事实、解释、目标和未知信息，再把判断写成可被新证据修正的假设。
2. 把研究证据、作者经验、书中轶事和融合演练分开；相关不自动成为因果。
3. 关系行动要保留双方自主、可拒绝和安全退出；不以技巧保证爱意或服从。
4. 恐惧、强迫、暴力与跟踪优先进入安全分诊，普通沟通不得覆盖这些信号。
5. 跨书结论列出全部支持来源；冲突、局限与未核事项不合并成共识。
6. 心理操纵材料主要供识别与边界应对；描述性机制不自动变成行动处方。

## 边界与判停

- 出现即时身体危险、暴力、跟踪、性强迫或威胁时，停止普通关系规划并优先安全。
- 用户要求操控、套取隐私、伪造共同点或绕过拒绝时，拒绝该执行路径并改给边界方案。
- 关键证据不支持用户期望的确定因果或结果时，明确不确定性和不可保证项。
