# 决策规则速查 — 小岛经济学

| 能力 | 一句话规则 |
|---|---|
| 资本形成与生产率增长链 | 先看生产率和产出能否覆盖当前消费、资本成本与失败风险，再谈增长。 |
| 贷款用途与还款来源审查 | 先分类贷款用途，再核对资金来源于储蓄、未来产出和可承受的失败损失。 |
| 储蓄供给、风险与利率信号 | 把利率拆成储蓄供给、风险、期限和政策干预后再判断项目。 |
| 货币扩张与价格变化分层诊断 | 先标明作者的通胀定义，再把货币、价格、产出和购买力分层核对。 |
| 分工、贸易与外部储蓄流向图 | 用相对优势、商品流向和外部资产/负债一起解释贸易与储备货币。 |
| 信贷担保、低利率与资产泡沫链 | 沿着担保—贷款条件—资产价格—偿债能力追踪泡沫，而不是只看涨幅。 |
| 危机后资源再配置判断 | 比较减少消费、扩大产出和继续借款三条路径，识别谁承担调整成本。 |
| 项目投资的生产率回报检验 | 把建设、维护、替代用途和真实收益放进同一张表，收益不足就不算增长。 |
| 劳动价值与收入提升路径 | 用需求、供给、生产力和工具获取路径分析收入，不把低薪归因于不努力。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
