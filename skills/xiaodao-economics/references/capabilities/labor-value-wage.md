# 劳动价值与收入提升路径

## R — 原文

> “一名员工的具体价值主要取决于三个方面”
> — 第五章“在鱼被指定为货币之后”，chunk `ck-f1cd22b8c9f6`

> “每个工作的人实际上都在经营着自己的生意，将自己的劳动力卖给出价最高的雇主。”
> — 第五章，chunk `ck-f1cd22b8c9f6`

## I — 解释

书中把劳动报酬拆成三个条件：雇主是否需要这项技能、有多少人具备这项技能、这名员工能把任务完成到什么程度。提高收入不是只靠更长时间或更辛苦，而是提高稀缺性、需求匹配和单位产出；拥有更好的工具或资本也可能提高同样劳动的价值。

取得生产工具的方式在书中有三条：节省消费自制、借款购买、为拥有工具的人工作。选择时要比较等待时间、风险、利息和自主性；不是所有人都能承受前两种。书中把就业视为自愿交换，但现实还受合同、议价权、歧视、教育和制度影响。

## A1 — 应用

**原书寓言案例（worked_example）**：芬尼根靠体力每天搬一百条鱼；莫里贷款造运鱼车，每天搬三百条并降低收费，随后雇芬尼根使用车辆，双方获得更高产出。书中用这个例子说明资本如何提高劳动价值，同时说明雇主利润来自承担风险和整合资源。见第五章，`ck-5ed90a25d547`。

## A2 — 何时使用

用户问“为什么同样努力收入差很多 / 我该学什么技能 / 要不要贷款买设备 / 打工还是自己干 / 怎么提高议价能力”，或需要用需求、供给、生产力分析职业选择时使用。英文 trigger：*wage, labor value, skill, productivity, career, bargaining*。

**与相邻能力的区分**：本卡处理个人劳动和技能；`productive-capital-growth` 处理宏观/项目资本；`loan-purpose-triage` 审购买设备的借款；`crisis-reallocation` 处理失业和宏观调整。

## E — 执行步骤

**输入契约**：目标岗位/任务；雇主需求；具备该技能的人数或替代难度；当前单位产出；可用工具/资本；获取工具的三条路径及成本；时间、风险和个人约束。

1. 写清任务和可验证产出，不用“努力”“热爱”代替。
2. 评估需求：谁需要、需求是否稳定、是否愿意付费。
3. 评估供给：具备技能的人数和替代难度；不把“熟悉”当成稀缺。
4. 评估生产力：单位时间产出、质量、错误率和工具支持。
5. 比较自制工具、借款购买、为他人工作三条路径的等待、风险和回报。
6. 给出一个可验证的提升实验（培训、工具、作品集、岗位转换），设定复盘指标。
7. 记录制度/议价限制；遇到歧视、合同或安全问题，转专业渠道。

**输出契约**：劳动价值表（任务、需求、供给、生产力、工具路径、成本/风险、实验、复盘指标）；结论是条件化建议，不保证涨薪。

## B — 边界

- 书中把就业视为自愿交换，未充分展开议价权、歧视、劳动法和集体行动；不能据此把低工资归因于个人不努力。
- 鱼模型没有教育认证、企业组织、技术变革和地区差异；现实职业决策需补充数据。
- 不提供法律、移民、税务或具体薪资谈判建议。
- 个人选择受照护责任和风险承受能力约束；不能把“贷款买设备”当成普适方案。

## 相关能力
