# 《小岛经济学》共享术语词典

> 这是本书语境下的术语表，不代表通用经济学辞书的唯一定义。术语按原文用法整理；作者立场和统计时效问题见 `needs-review.md`。

| 术语 | 本书中的用法 | 与常识用法的差异 | 出处 |
|---|---|---|---|
| 生产率 | 用更好的工具、组织或技术，在同等劳动下生产更多所需产品和服务的能力。 | 不是单纯的劳动时间或努力程度；书中把工具和资本带来的单位产出提高作为增长核心。 | 第一章；第四章；`ck-a7ad35404e4f` |
| 资本 | 为了生产其他有用物品而建设和使用的设备；渔网是捕鱼的工具，不是最终消费品。 | 不是泛指任何资产或货币；书中强调它能否帮助生产更多所需物品。 | 第一章；`ck-a7ad35404e4f` |
| 储蓄 | 没有用于当前消费的真实产出，可留作未来消费、贷款、投资或应急缓冲。 | 不是“闲置的钱”或单纯消费漏损；书中把鱼的不腐坏作为寓言假设。 | 第二、四章；`ck-357c8dce28d9` |
| 商业贷款 | 用于扩大生产或创业的借款，可能通过新增产出获得还款来源。 | 与消费贷款、应急贷款不同；商业贷款也不保证成功。 | 第三章；`ck-e47f26090423` |
| 消费贷款 | 用于假期或其他当前消费、本身不提高借款人生产能力的贷款。 | 如果未来收入不增加，偿还只能压缩未来消费；不能因为借款发生就视为投资。 | 第三章；`ck-e47f26090423` |
| 应急贷款 | 在疾病、灾害等紧急情况下提供的贷款，用于避免更大的生命或生产能力损失。 | 与消费享乐贷款的理由不同；书中仍承认可能收不回。 | 第三章；`ck-e47f26090423` |
| 利率 | 贷款风险、储蓄可用性、期限和消费时间偏好的价格信号。 | 书中把央行设定的基准利率视为可能扭曲信号的干预，不等于市场自然利率。 | 第六章；`ck-0ae8f55bbd47` |
| 通货膨胀 | 书中指货币供应量增加；物价上涨是可能的结果。 | 与日常“物价上涨就是通胀”的用法不同，须标明作者定义和统计口径。 | 第十章；`ck-dc1196339503` |
| 通货紧缩 | 在货币层面指货币供应收紧；书中也讨论生产率提高带来的价格下降和危机中的价格下行。 | 不等于所有降价；需要区分货币、供需和生产率来源。 | 第五、十、十七章；`ck-f1cd22b8c9f6` |
| 法定货币 | 本身没有内在价值、因政府命令或普遍接受而作为交换媒介的纸币。 | 其价值依赖信任和制度，不是由可兑换商品自动保证。 | 第十三章；`ck-b3957e39d603` |
| 量化宽松 | 央行通过购买债券或资产向金融系统注入货币、压低利率并支撑资产价格的政策；书中称之为印钞的委婉说法。 | 这是作者的机制解释与评价，现实央行操作、资产构成和传导渠道更复杂。 | 珍藏版序言；第十七、十八章；`ck-f622cedf22a1` |
| 比较优势 | 各方生产自己相对更擅长或机会成本较低的产品，再通过交换获得其余产品。 | 不是绝对生产能力最强才参与贸易；书中用小鼓和防晒油说明相对优势。 | 第七章；`ck-e1cd4045c644` |
| 储备货币 | 在国际交换中被广泛接受、用于结算和储备的货币；书中用鱼邦储备券映射美元地位。 | 储备地位带来需求，但不等于无限信用或没有调整成本。 | 第十一、十二、十九章；`ck-e5a7e283b538` |
| 资产泡沫 | 资产价格由信贷扩张、预期和再融资推动，超过其可持续现金流或真实需求的部分。 | 价格上涨本身不等于泡沫；书中要求看信贷、首付、收入和偿债能力。 | 第十四至十八章；`ck-b8b0e9405c2a` |
| 政府担保 | 政府或准政府机构为贷款损失提供隐性或显性支持，降低放款人的风险感知。 | 担保不消除风险，而是把损失转移给纳税人或未来债权人。 | 第十四章；`ck-b8b0e9405c2a` |
| 通鱼膨胀 | 寓言中官鱼变小、以更多鱼换取同样生活水平的现象，用来映射通货膨胀。 | 是故事化术语，不是现实统计指标；现实对应要看货币、价格和购买力。 | 第十章；`ck-dc1196339503` |
| 经济停滞型通货膨胀 | 货币过多与产出不足并存，价格上升而经济停滞的现象。 | 不是所有通胀都伴随繁荣；供给收缩和货币扩张可以同时发生。 | 第十章；`ck-dc1196339503` |
| 资本设备 | 用于生产其他商品和服务的工具、机器或设施，例如渔网、巨型捕鱼器、运鱼车。 | 与最终消费品相对；是否值得建设取决于未来产出和成本。 | 第一、四章；`ck-a7ad35404e4f` |

## 使用规则

- 回答现实问题时，先标明“书中定义”还是“通用统计定义”。
- 书中的“鱼”“官鱼”“鱼邦储备券”“两棚”等是寓言化表达，不能直接替换成现实机构。
- 术语只帮助统一口径，不单独构成可执行能力；需要流程时读对应能力卡。
