# 相互依赖与承诺检查

## R — 原文依据

> “满意度、替代选择的质量和个体投入的数量，每一项都能告诉我们个体承诺程度的有用信息。”  
> —《亲密关系》第6章，`ck-b5ec156d893d`

> “高质量的替代选择会削弱承诺。”  
> —同上

## I — 解释

关系是否继续，不只取决于“爱不爱”。奖赏、代价、个人期待、离开后的选择、已投入的资源与公平感共同描述当前承诺。这个模型帮助区分“满意但投入少”“不满意但缺少替代”“高投入导致难退出”。模型是描述工具，不是要求用户做成本核算后服从结果；安全、价值观、尊严和长期目标可以改变结论。

## A1 — 演练

**合成演练，非书中案例。** 小安说“我们在一起五年，我舍不得分，但每次沟通都很累”。分别填写：满意项/耗损项、希望被怎样对待、离开后有哪些支持与选择、已投入什么、是否公平。模型可能提示“投入高但满意度低”，下一步不是自动分手，而是先验证问题能否改变、评估安全与价值观，并设复查窗口。

## A2 — 何时调用

适用：“该不该继续”“条件不错但没有感觉”“分手后会不会更差”“我是不是只是因为习惯才留下”。

不适用：暴力安全危机与即时人身风险；单纯问爱情类型。与关系维护、冲突、安全卡相邻；本卡只做承诺结构检查。

## E — 执行

**输入契约：** 关系阶段；3 个以上具体满意/不满意事件；可替代现实的资源/支持；已投入；公平感和安全状态。

1. 填“奖赏 / 代价 / 期待基准 / 可替代选择 / 已投入 / 公平 / 安全”七项。
2. 分开事实、主观评价和未知；避免用“我付出五年”替代关系质量。
3. 辨认承诺来源：满意、义务、缺少替代、投入、共同身份；不必只取一项。
4. 检查改变空间：哪一项可协商，哪一项是不可接受的底线，哪一项需要外部支持。
5. 设计一个时间盒试验（如 4 周具体互动），同时列退出/求助条件。
6. 输出“现状—可试验—不可接受—复查日期”。

**完成标准：** 没有把高投入自动解释为应继续；没有把替代选择窄化为“有没有新对象”；安全与公平被单独记录。

## B — 边界

- 不替用户决定分手/留下；模型不是幸福裁判。
- 不用经济语言给伴侣标价、衡量人格价值或合理化控制。
- 不把沉没成本当道德义务；不发“离开会后悔”的保证。
- 暴力、强迫或严重依赖先转安全/专业支持。
