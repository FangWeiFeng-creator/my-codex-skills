# My Codex Skills

This repository contains three independently scoped Codex skills. Each skill lives in its own folder and includes its own `SKILL.md` and supporting references.

- `skills/xiaodao-economics/`
- `skills/four-book-relationship-compass/`
- `skills/life-direction-compass/`

Install a skill by pointing your skill installer to its folder inside this repository. The skills are kept separate; no book source files are included.
