# My Codex Skills

This repository contains four independently scoped Codex skills. Each skill lives in its own folder and includes its own `SKILL.md` and supporting references.

- `skills/xiaodao-economics/`
- `skills/psychology-emotional-skill/`
- `skills/life-direction-compass/`
- `skills/ai-employee-orchestration/`

Install a skill by pointing your skill installer to its folder inside this repository. The skills are kept separate; no book source files are included.
